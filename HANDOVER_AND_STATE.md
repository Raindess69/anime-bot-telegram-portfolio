## 1. Что сделано в текущей сессии

### 1.1. Telegram Mini App (TMA) & Web API
1. **Создан легковесный Web API (`web_api.py`)**:
   - На базе **FastAPI** + **Uvicorn**, встроен в ту же кодовую базу и использует существующие SQLite сервисы (`db/user_titles.py`, `services/aggregator.py`, `services/shikimori.py`, `services/kodik.py`).
   - Эндпоинты:
     - `GET /api/feed` — подборки (онгоинги, популярное, топ рейтинга, hero-баннер дня).
     - `GET /api/search?q=...` — поиск аниме по базам.
     - `GET /api/anime/{id}` — карточка тайтла с плеером Kodik и списком доступных серий.
     - `GET /api/vibe` — умная фильтрация по эпохам (2020-е, 2010-е), минимальному рейтингу и жанрам.
     - `GET /api/random` — быстрое открытие случайного аниме.
     - `GET /api/library`, `POST /api/library/status`, `POST /api/library/episode`, `POST /api/library/favorite` — синхронизация пользовательской библиотеки (Смотрю, В планах, Просмотрено, Избранное).
     - Раздача статики `GET /` -> `static/index.html`.

2. **Создан интерфейс Mini App (`static/index.html`)**:
   - Dark-mode дизайн (Tailwind CSS, шрифт *Plus Jakarta Sans*, стекломорфизм, неоновые акценты).
   - Встроенный кинотеатральный плеер Kodik с выбором серий и озвучек.
   - Адаптивный респонсив (`max-w-4xl`): идеальный вид как на мобильных клиентах Telegram (iOS/Android), так и на Telegram Desktop / веб-браузере.
   - Интеграция с Telegram WebApp SDK (`Telegram.WebApp.ready()`, `expand()`, `HapticFeedback`).

### 1.2. Исправление визуальных дефектов и багов
1. **Устранены 404 битые постеры**:
   - Заменены переадресации `shikimori.one` на прямой рабочий домен `shikimori.io`.
   - В API внедрена фильтрация: тайтлы с пустыми или плейсхолдерными картинками (`missing_original.jpg` со штампом 404) исключаются из подборок (36 из 36 карточек теперь с подтвержденными постерами).
   - Создан offline-векторный SVG fallback постер (логотип EnjoyAnime на темном градиенте), предотвращающий любые поломки картинок в интерфейсе.
2. **Очистка описаний от BBCode и HTML**:
   - На бэкенде в `services/shikimori.py` добавлен метод `_clean_bbcode()` (удаляет теги `[character=...]`, `[/character]`, `[anime]`, `[b]` и т.д., сохраняя имена и полезный текст).
   - На фронтенде добавлена клиентская функция `sanitizeDescription()`, очищающая описание даже при локальном кэше.
   - Заголовок блока изменен с технического *"Синопсис"* на понятное *"Описание"*.
3. **Устранена "рваность" карточек**:
   - Создана единая функция `renderCardHTML()` для каруселей, поиска и вайб-фильтра.
   - Зафиксирована пропорция 2:3 (классический формат аниме-постеров).
   - Зафиксирована высота заголовков тайтлов (`h-8`, 2 строки с line-clamp), благодаря чему все карточки в строках и сетках выровнены идеально по пикселям.
4. **Интерактивные кнопки и уведомления**:
   - Добавлены toast-уведомления (`showToast()`) при смене статуса или добавлении в избранное.
   - Добавлена визуальная подсветка активной серии в плеере (`#ep-btn-{N}`) и активного статуса в библиотеке (`.status-btn-active`).

### 1.3. Инфраструктура хостинга на muse.ai (100% бесплатно)
1. **Бесплатный HTTPS-туннель (Pinggy / Cloudflare)**:
   - Поднят туннель через SSH порт 443 (`tunnel.py`). Внешний URL: `https://*.run.pinggy-free.link` (или Cloudflare `*.trycloudflare.com`).
   - Добавлен supervisor loop в `tunnel.py`: непрерывное чтение stdout (исключает переполнение буфера каналов SSH), автоматический реконнект через 3с при разрыве.
   - Внедрена поддержка Cloudflare Quick Tunnel (`cloudflared`): при наличии бинарника работает без промежуточных экранов-предупреждений.
   - В `bot.py` запущен фоновый наблюдатель `watch_url_changes()`, который каждые 4с сверяет URL из `.env` и мгновенно обновляет кнопку меню `MenuButtonWebApp` в Telegram без перезапуска бота.
   - В команду `/app` добавлены две кнопки: Mini App и прямая ссылка в браузер.
   - В выдачу поиска бота (`handlers/search.py`) и рассылку новых серий (`services/scheduler.py`) встроена кнопка «📺 Открыть в EnjoyAnime (Mini App)» с deep-link (`#title/{mal_id}`).
2. **Обработка ротации прокси в песочнице**:
   - При смене egress IP и протухании токена прокси бот ловит ошибку 407 (`Proxy Authentication Required`) и завершает процесс с кодом `1`.
   - Минутный watchdog отслеживает статус и перезапускает бота через `restart_bot.sh` в свежей сессии с новыми переменными окружения.

## 3. Команды для запуска

### Локальный запуск Mini App (только веб-сервер):
```powershell
cd C:\Users\MainAdmin\Desktop\Claude\anime-bot
.venv\Scripts\python.exe -m uvicorn web_api:app --host 127.0.0.1 --port 8080 --reload
```
Доступно в браузере: `http://127.0.0.1:8080`

### Полный запуск (Telegram бот + Mini App вместе):
```powershell
cd C:\Users\MainAdmin\Desktop\Claude\anime-bot
.venv\Scripts\python.exe bot.py
```
*Бот запускает polling Telegram, настраивает кнопку MenuButtonWebApp и поднимает uvicorn на порту 8080.*

## 4. Недавние улучшения

1. **Валидация Telegram `initData` (HMAC-SHA256)**:
   - Внедрена криптографическая проверка подписи данных Telegram WebApp через секретный ключ бота (`verify_telegram_init_data`).
   - Исключена подделка `user_id`: клиент автоматически передаёт заголовок `X-Telegram-Init-Data`.
   - Добавлен эндпоинт `GET /api/user/me`.
   - Добавлен эндпоинт `GET /api/library/title/{mal_id}` для мгновенной подгрузки статуса тайтла (Смотрю, Избранное, номер серии) при открытии модалки.

2. **Синхронизация прогресса воспроизведения (Kodik / PlayerJS `postMessage`)**:
   - Реализован слушатель межфреймовых событий плеера (`kodik_player_time_update`, `kodik_player_video_ended`, `time`, `finish`).
   - Добавлен эндпоинт `POST /api/library/progress`: автосохранение позиции каждые 20 сек.
   - При просмотре 85%+ хронометража серия автоматически отмечается как просмотренная с toast-уведомлением и бейджем `✓`.

3. **Секция «Продолжить просмотр» на главной странице**:
   - На главном экране выводится персональная горизонтальная карусель с постерами тайтлов со статусом «Смотрю», номером текущей серии и кнопкой быстрого возобновления просмотра.
   - В SQLite таблицу `user_titles` добавлена колонка `image_url` с авто-миграцией, сохраняющая постеры в локальную базу.

4. **Выбор озвучки в плеере (мульти-перевод Kodik)**:
   - В `services/kodik.py` расширен метод `get_player`: парсинг всех доступных озвучек (AniLibria, Studio Band, SHIZA Project, Субтитры и т.д.).
   - Добавлен эндпоинт `GET /api/player/{anime_id}?translation_id=...` для бесшовного переключения звуковой дорожки в 1 клик прямо в модалке.

5. **Модальное окно профиля и аналитики**:
   - Клик по бейджу пользователя в шапке открывает интерактивный профиль с персональной статистикой: просмотрено серий (`episodes_watched`), количество тайтлов в «Смотрю», «В планах», «Просмотрено», «Избранное».
   - Эндпоинт `GET /api/user/stats`.

6. **Быстрые жанровые фильтры на поиске**:
   - На вкладке «Поиск» добавлены горизонтальные чипы жанров (Экшен, Романтика, Комедия, Фэнтези, Сёнен, Детектив, Драма), позволяющие искать тайтлы мгновенно.

7. **Постеры в библиотеке «Мой список»**:
   - Карточки в списке пользователя теперь отображают обложки аниме, статус и кнопку инкремента серий `+1 эп.`.
