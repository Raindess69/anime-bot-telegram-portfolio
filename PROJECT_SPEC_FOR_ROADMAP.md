# 🎌 EnjoyAnime Bot — Полная техническая спецификация и архитектурный отчёт для составления Роадмапа (Telegram Mini App / Visual Platform)

> **Назначение документа:** Полное, детальное описание текущего состояния кодовой базы, архитектуры, интеграций, структуры базы данных и бизнес-логики проекта **EnjoyAnime** (@AnimeSpaceFree_bot). Документ подготовлен как входной контекст для **Claude Opus 5.5** для проектирования архитектуры и пошагового роадмапа перехода от текстово-кнопочного Telegram-бота к современному визуальному приложению (**Telegram Mini App / WebApp**).

---

## 1. Обзор проекта и текущее позиционирование

**EnjoyAnime** — это многофункциональный Telegram-бот для поиска, каталогизации, трекинга и просмотра аниме.
- **Текущий стек:** Python 3.11+, `aiogram 3.4+`, `aiosqlite`, `pydantic v2`, `httpx`, `python-dotenv`.
- **Языки интерфейса:** Русский (`ru`), Украинский (`uk`), Английский (`en`).
- **Ключевая ценность:** Единый агрегатор контента, объединяющий метаданные мировых баз (MyAnimeList, AniList, Shikimori) и прямые источники просмотра для СНГ-аудитории (AniLibria, Kodik, YummyAnime, Crunchyroll), с персональным трекером («Смотрю», «В планах», «Просмотрено», «Брошено»), подписками на онгоинги и бэкапом данных.

## 3. Схема данных и хранилище (SQLite / aiosqlite)

База данных хранится в SQLite (`bot.db`). Архитектура нормализована под реляционные операции:

### 1) Таблица `users`
- `user_id` (INTEGER PRIMARY KEY) — Telegram ID пользователя.
- `lang` (TEXT NOT NULL DEFAULT 'ru') — Язык интерфейса (`ru`, `uk`, `en`).

### 2) Таблица `subscriptions` (Версия v2)
Ориентирована на отслеживание релизов онгоингов:
- `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
- `user_id` (INTEGER NOT NULL, INDEX)
- `mal_id` (INTEGER, UNIQUE с user_id) — Ключевой идентификатор аниме по MyAnimeList.
- `anilibria_code` (TEXT) — Код тайтла в AniLibria (например, `mushoku-tensei-iii`).
- `yummy_url` (TEXT) — Прямая ссылка на страницу тайтла на YummyAnime.
- `shikimori_id` (INTEGER) — ID на Shikimori.
- `title` (TEXT NOT NULL) — Название аниме на языке пользователя.
- `lang` (TEXT NOT NULL DEFAULT 'ru')
- `last_episode` (INTEGER NOT NULL DEFAULT 0) — Номер последнего просмотренного/оповещённого эпизода.
- `created_at` (INTEGER NOT NULL) — UNIX-timestamp подписки.

### 3) Таблица `user_titles` (Персональный трекер библиотеки)
Хранит статус и прогресс по каждому просмотренному тайтлу:
- `user_id` (INTEGER NOT NULL)
- `mal_id` (INTEGER NOT NULL)
- `title` (TEXT NOT NULL)
- `lang` (TEXT NOT NULL DEFAULT 'ru')
- `status` (TEXT NOT NULL DEFAULT 'watching') — Допустимые статусы:
  - `watching` — Смотрю
  - `completed` — Просмотрено
  - `plan` — В планах
  - `dropped` — Брошено
- `current_episode` (INTEGER NOT NULL DEFAULT 0) — Номер серии, на которой остановился пользователь.
- `is_favorite` (INTEGER NOT NULL DEFAULT 0) — Флаг избранного (0 или 1).
- `updated_at` (INTEGER NOT NULL) — UNIX-timestamp обновления.
- *PK:* `(user_id, mal_id)`
- *INDEX:* `(user_id, status)`

### 4) Таблица `search_history`
- `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
- `user_id` (INTEGER NOT NULL, INDEX)
- `query` (TEXT NOT NULL) — Текст поискового запроса.
- `ts` (INTEGER NOT NULL) — Время запроса. Хранятся последние 10 запросов на пользователя.

## 4. Пайплайн агрегации данных (Services & Data Flow)

Сердце системы — модуль `services/aggregator.py`. Он объединяет 6 независимых провайдеров в отказоустойчивую цепочку:

```
                  ┌──────────────┐
                  │ Пользователь │
                  └──────┬───────┘
                         │ Поиск / Каталог / Vibe
                         ▼
             ┌─────────────────────────┐
             │       Aggregator        │
             └───────────┬─────────────┘
                         │
      Параллельный опрос метаданных с fallback:
      ├── Shikimori API (RU названия, синонимы, ID)
      ├── AniList GraphQL (Высокая скорость, жанры, трейлеры, стримы)
      └── Jikan / MAL (Рейтинги, расширенные фильтры, жанры)
                         │
                         ▼
             ┌─────────────────────────┐
             │ Слияние по mal_id       │ (Dedup & Field Enrichment)
             └───────────┬─────────────┘
                         │
      Параллельное обогащение плеерами и стримингами:
      ├── AniLibria (HLS плеер, UUID серий, .torrent файлы)
      ├── Kodik (iframe плеер, озвучки, номера серий)
      ├── YummyAnime (страницы для онлайн-просмотра)
      └── Crunchyroll (через AniList externalLinks)
                         │
                         ▼
             ┌─────────────────────────┐
             │  Итоговый AnimeCard     │
             └─────────────────────────┘
```

### Детали интеграций:
1. **AniList (`services/anilist.py`):**
   - Прямой GraphQL без авторизации (`https://graphql.anilist.co`).
   - Идеален для мгновенной выдачи без прокси.
   - Метод `get_streams_by_mal(mal_ids)` пакетно (batch) за один HTTP-запрос достаёт официальные стриминговые ссылки (Crunchyroll, Netflix).
2. **Jikan / MyAnimeList (`services/jikan.py`):**
   - Имеет умный ротатор прокси (если настроен `JIKAN_PROXIES`), экспоненциальный retry и тихий fallback. Если Jikan недоступен или падает по тайм-ауту — агрегатор автоматически переключается на AniList GraphQL.
3. **AniLibria (`services/anilibria.py`):**
   - Полноценная интеграция с API AniLibria. Получает список серий, прямые UUID для плеера и список торрент-раздач (качество, сиды, размер в ГБ, возможность скачать `.torrent` прямо в Telegram).
4. **Kodik (`services/kodik.py`):**
   - Интеграция с крупнейшей базой озвучек СНГ через партнерский токен. Позволяет получать прямой iframe плеера и ссылки на конкретные серии с нужными переводами.
5. **Планировщик онгоингов (`services/scheduler.py`):**
   - Каждые 12 часов сканирует активные подписки из БД.
   - Проверяет AniLibria, YummyAnime, Kodik и Shikimori на появление новых эпизодов (`max_ep > last_episode`).
   - Если вышла новая серия — отправляет пользователю уведомление с кнопками прямого перехода к просмотру.

## 5. Текущий интерфейс и функционал (Telegram Bot UX)

1. **Главное меню (Reply Keyboard 3x3):**
   - 🔍 *Поиск* — контекстный текстовый поиск.
   - 🎲 *Вайб* — пошаговый FSM-визард: выбор года (эпохи) ➔ минимального рейтинга (6+, 7+, 8+, 9+) ➔ жанра ➔ формата (TV, Фильм, OVA, Любой).
   - 📋 *Мой список* — интерактивный трекер по категориям («Смотрю», «В планах», «Просмотрено», «Брошено», «Избранное», «Статистика»).
   - 🏆 *Топ* — выбор категорий: общий, онгоинги, анонсы, популярное, фильмы, текущий сезон.
   - 🎰 *Рандом* / `/planrandom` — случайное аниме из каталога или случайный выбор из собственного списка «В планах».
   - 🔔 *Подписки* — управление отслеживанием выхода серий.
   - 🕒 *История* — последние 10 поисковых запросов.
   - ❓ *Помощь* — документация команд.
   - ⭐️ *Поддержать* — донаты в Telegram Stars (50, 100, 250, 500 XTR).
2. **Инлайн-режим:**
   - Вызов бота в любом чате: `@EnjoyAnimeBot <название>` — выдаёт список карточек с постерами, рейтингом и быстрой ссылкой на просмотр.
3. **Бэкап и миграция:**
   - `/export` — выгружает всю библиотеку пользователя в валидный JSON-файл.
   - `/import` — принимает JSON-файл и восстанавливает статусы, просмотренные серии и избранное.

## 6. Почему переход в WebApp / Mini App необходим (Боли и ограничения)

Текущий формат классического бота на `InlineKeyboardButton` уперся в технический и пользовательский потолок:

| Аспект | Ограничение текущего Telegram-бота | Возможность в Telegram Mini App (TMA) |
|---|---|---|
| **Видеоплеер** | Нельзя встроить видеоплеер в чат; пользователя перекидывает по внешним ссылкам в браузер | Встроенный плеер (Kodik iframe / HLS AniLibria) прямо внутри Telegram без выхода из приложения |
| **Интерфейс каталога** | Неудобные кнопки `[1] [2] [3]`, медленное редактирование сообщений через API Telegram | Сетка карточек в стиле Netflix/Kinopoisk, бесконечный скролл, горизонтальные карусели |
| **Фильтры (Vibe)** | 4 шага вопросов-ответов через бота, долгое ожидание кликов | Удобный выпадающий Drawer/BottomSheet с ползунками (слайдер годов, мультивыбор жанров, рейтинг) |
| **Управление трекером** | Клик по кнопке `Статус` каждый раз перезагружает клавиатуру сообщения | Быстрый свайп, перетаскивание, кнопки `+1 серия`, выставление оценки 1-10 звезд в один клик |
| **Ограничение данных** | Лимит Telegram `callback_data` всего **64 байта** (приходится урезать данные и хранить стейт в кэше) | Полноценный REST API / JSON без ограничений на размер передаваемых объектов |
| **UX & Визуал** | Черно-белый чат, мелкие постеры, текст описания часто обрезается лимитом длины подписи (1024 символа) | Полноэкранный адаптивный UI с темной/светлой темой, баннерами, трейлерами с YouTube, отзывами |

## 7. Целевое видение: Концепция Telegram Mini App

### Архитектурная трансформация:
1. **Бэкенд:**
   - Существующий код на Python оборачивается в **FastAPI** (или запускается параллельно с aiogram в едином event loop).
   - Все функции из `services/aggregator.py`, `services/anilibria.py`, `services/kodik.py`, `db/user_titles.py` становятся эндпоинтами REST API:
     - `GET /api/anime/{mal_id}` — полная карточка с плеерами и сериями.
     - `GET /api/catalog/feed` — лента (Тренды, Топ сезона, Онгоинги, Рекомендации).
     - `POST /api/user/track` — обновление статуса, серии, оценки.
     - `GET /api/user/library` — вся библиотека пользователя с группировкой по статусам.
     - `POST /api/anime/filter` — мгновенный вайб-поиск по фильтрам.
2. **Аутентификация:**
   - Бесшовная через `Telegram.WebApp.initData`.
   - Бэкенд валидирует HMAC-подпись через `BOT_TOKEN`. Пользователю не нужны логины и пароли — Telegram ID подтягивается автоматически.
3. **Фронтенд (Mini App):**
   - Современный SPA на **React / Next.js / Vue 3 + Tailwind CSS / shadcn/ui** или **Telegram UI Components**.
   - Адаптация под мобильные экраны и десктопный клиент Telegram.
   - Поддержка Haptic Feedback (виброотклик при кликах через Telegram WebApp SDK).
4. **Связка с ботом:**
   - Бот остаётся точкой входа и каналом уведомлений:
     - Кнопка внизу экрана: **«📺 Открыть EnjoyAnime»** (запускает Mini App).
     - Пуш-уведомление от планировщика: *"Вышла 5 серия Ре:Зеро!"* ➔ кнопка открывает Mini App сразу на плеере 5 серии.
